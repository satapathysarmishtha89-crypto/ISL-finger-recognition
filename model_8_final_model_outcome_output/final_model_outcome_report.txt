------------------------------------------------------------------------------------
1. STEP 8: FINAL MODEL SPECIFICATION
------------------------------------------------------------------------------------
• Architecture: Hybrid CNN + Landmark Late Fusion
• CNN Visual Feature Branch: MobileNetV2 (1280-D global average pooled embeddings)
• Geometric Landmark Branch: MediaPipe 42-D Normalized Joint Coordinates (128->64->35 DNN)
• Optimal Fusion Weight: w = 0.69 (CNN weight: 69%, Landmark weight: 31%)
• Dynamic Fallback Strategy: Confidence-Aware fallback to pure CNN when no landmarks detected
• Output Layer: 35-Class Softmax Probability Vector (Sum of all 35 class probabilities = 1.0)
• Model Footprint: 3,521,291 parameters (~13.43 MB on disk)
• Inference Latency: ~0.0050 ms per image on standard CPU (real-time 60+ FPS capable)

------------------------------------------------------------------------------------
2. STEP 9: MODEL OUTCOME SPECIFICATION
------------------------------------------------------------------------------------
• Core Objective: Generate the predicted sign class for any input hand sign image.
• Decision Rule: Predicted Class y_hat = argmax_c P(c | input)
• Confidence Score: c = max_c P(c | input) * 100%
• Ambiguity Quantification: Margin = P(top_1) - P(top_2)
  - When Margin > 30%: Model is unambiguous and definitive.
  - When Margin <= 30%: Model detects visual similarity between top-2 signs and triggers
    Gemini Sign Guidance to explain the precise physical difference to the user.
